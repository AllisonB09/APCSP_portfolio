# APCSP_portfolio
Collection of projects I did during AP computer science principles


Project Title: Dog Program

Summary: This Python program works with dog-related data and demonstrates the use of variables, functions, or classes. It allows users to organize or interact with information about dogs in a structured way.
Key Features: Uses object-oriented programming concepts and user interaction.

Project Title: Grocery List Program
Summary: This project simulates a grocery shopping or grocery list system. Users can add, remove, or organize items using lists and basic Python logic.
Key Features: Demonstrates list management, loops, and user input.

Project Title: Hiring System Program
Summary: This program models a hiring process by organizing applicant information and making decisions based on conditions. It practices logical thinking and decision-making in Python.
Key Features: Uses conditionals and input-based decision making.

Project Title: Hogwarts Sorting Program
Summary: This Harry Potter–themed project interacts with users and sorts them into Hogwarts houses or displays house-related information. It combines creativity with programming logic.

Project Title: Image Processing Program
Summary: This project works with image files by displaying, editing, or manipulating pictures through Python code. It explores how programming can interact with digital media.
Key Features: Demonstrates image manipulation and file handling.

Project Title: Nickname Generator
Summary: This program creates or stores nicknames based on user input. It practices working with strings and personalized outputs.
Key Features: Uses string manipulation and interactive user responses.

Project Title: Peaks Analysis Program
Summary: This project analyzes patterns or identifies peaks within numerical data. It demonstrates problem-solving skills through data analysis techniques.

Project Title: Final Python Project

Project Title: Slot Machine Game
Summary: This project simulates a slot machine game where users can spin for randomized outcomes. It recreates the experience of a simple casino-style game using Python.

Project Title: To-Do List Application
Summary: This program helps users manage tasks by creating and organizing a to-do list. It demonstrates how programming can be used for productivity and organization.
